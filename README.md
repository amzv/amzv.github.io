## 🏛 Design Philosophy: Modern Industrial Minimalist

This site is purposefully designed to avoid generic AI-generated aesthetic tropes (neon gradients, glassmorphism cards, Inter-only typography). Instead, it adopts a **Modern Industrial Minimalist** visual identity inspired by Swiss graphic design, technical blueprint grids, and telemetry logs:

- **Canvas & Palette:** Warm stone / paper background (`#F9F8F5`), high-contrast dark typography (`#111317`), structural hairline rules (`#E2DDD3`), and an aerospace safety orange accent (`#D84A1B`).
- **Typography:** `Space Grotesk` (editorial titles & headlines), `Inter` (body copy), and `IBM Plex Mono` (telemetry readouts, indices, and metadata badges).
- **Architecture:** Zero-dependency, pure semantic HTML5 and Vanilla CSS3 — 100% natively compatible with GitHub Pages out of the box with zero build step.

## 🚀 Deployment to GitHub Pages

1. Push this repository to the `main` branch:
   ```bash
   git add .
   git commit -m "Deploy modern industrial minimalist portfolio"
   git push origin main
   ```
2. In your repository on GitHub, navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, ensure `main` and `/(root)` are selected.
4. GitHub Pages will automatically publish the site at `https://amario.github.io/`.
